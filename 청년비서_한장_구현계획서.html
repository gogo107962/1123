01최소 기능과 차별점

  • 조건 확인: 충족·불충족·확인 필요와 공고 근거. 현재 상태와 응시일 당시 상태를 구분.
  • 서류 점검: 보유 여부·발급일·기재 항목을 대조하고 직접 준비와 공식 창구 연동을 구분.
  • 행동 갱신: 준비 상태가 바뀌면 남은 할 일을 다시 구성. 필수 미확인은 완료 처리 차단.

제외: 자동 신청·발급, 실제 서류 OCR, 소득 자동 환산.
여러 정책의 서류 통합은 필수 기능 완성 후 검토.

전처리는 로컬 Python으로 수행하고 승인 자료만 배포한다. 변경 공지·기준일·빈값을 검수한다. 무료 호출 한도는 서버에서 제어하며, 초과 시 유료 전환 없이 AI 중단을 표시한다.

데이터·키 보호: 무료 Gemini는 입력·출력을 제품 개선에 이용할 수 있다. 공개 공고와 합성 프로필만 전송하고 API 키는 Worker Secret에 저장한다. 실제 개인정보·기밀자료는 전송하지 않는다.
