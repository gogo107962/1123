오늘 한 일 진행 순서

위에서 아래로 진행했습니다.

  1. 1전국 정책 전체 수집
    1,000건씩 5번 호출해 4,016건. 서버 건수와 같고 중복 없음.
  2. 2데이터 진단 보고서
    항목 60개가 얼마나 채워져 있는지, 소득·나이·신청기간·지역 상태를 표로 정리.
  3. 3지역 코드 확인
    행정안전부 법정동코드 20,560건으로 확인. 광주·전남은 새 코드 12(전남광주통합특별시).
  4. 4기준과 지역 결정
    등급은 기본 기준, 시연 지역은 전국 대상 + 서울 + 충남 아산시.
  5. 5공고 원문 대조
    공고 페이지 171개를 받아 45건을 API 값과 비교. 근거 문장 263개가 원문에 그대로 있는지 프로그램으로 검사(실패 0).
  6. 6최종 후보 데이터셋 + 로드맵 추가
    후보 26건 정리. 구현 로드맵에 "매일 최신화, 두 단계로 보여주기"를 추가.

팀이 할 일

다음 작업을 시작하기 전에 필요한 것들입니다.

  • 검수최종 후보 26건을 원문과 맞춰 보기정책마다 근거 문장과 출처 주소가 붙어 있습니다. 문장이 원문과 같은지, "일치/불일치" 판정이 맞는지만 확인하면 됩니다. 끝난 정책은 사람_검수_완료를 true로 바꿉니다.
  • 검수사람이 직접 확인해야 하는 곳한부모 아동양육비 금액(두 원문이 서로 반대), 자립수당 보호종료 기간(5년 이내 / 3년 이내), 첨부파일(HWP·PDF)에만 있는 제출서류.
  • 자료서울 청년 월세 지원의 2026년 공고 주소 찾기찾은 주소를 data/notice_url_overrides.json에 넣으면 추가 대조가 가능합니다. 기후동행카드 청년할인도 같은 상태입니다.
  • 문의운영사무국에 "마감 뒤 자동 데이터 갱신" 가능 여부 문의답에 따라 매일 최신화를 마감 전까지만 돌릴지 정합니다.
  • 결정구현을 언제 시작할지검수가 끝나기를 기다릴지, 검수와 판정 코드를 함께 진행할지 정해야 합니다.
  • 선택충남청년포털 17건사이트가 자동 접속을 끊어 받지 못했습니다. 아산 후보를 늘리려면 브라우저로 페이지를 저장해 주면 대조할 수 있습니다.
