## 7. 같은 PC에서 가장 안전하게 이어가기

1. 새 프로젝트의 작업 폴더를 기존 루트로 선택한다.
2. `00_새채팅_시작프롬프트.md`의 구분선 아래를 붙여 넣는다.
3. 앱소스·DB·키·모델은 기존위치에 있으므로 다시복사/재수집할필요가없다.
4. 새 에이전트가현재서버/테스트상태를확인하고 마지막미검증변경부터이어간다.

## 8. 다른 폴더·PC로 이전

1. `청년비서_새채팅_인계패키지_2026-11-17.zip`을 **새 빈 폴더**에 푼다.
2. `HANDOFF_2026-11-17/`와 `youth_secretary_ready/`, 루트문서, `references/`, `evidence/`를확인한다.
3. 기존 `.venv`는패키지에없다. Python설치후새venv를만든다.
4. Ontong검색/준비판은포함DB만으로시작가능. 신규수집만API키필요.
5. AI가필요하면Ollama와qwen3:4b모델준비. 기존PC에서는기존store재사용우선.
6. 시작프롬프트작업위치를새루트로고친다.
7. 기존브라우저workspace복원은localStorage의동일토큰이필요. 다른브라우저에계정처럼자동연결되지않는다. DB안에이전공간은보존되어있으므로삭제하지않는다.

## 9. 실행 명령 (PowerShell)

```powershell
Set-Location -LiteralPath 'C:\Users\User\Documents\ChatGPT\대한상공회의소 해커톤\youth_secretary_ready'

# 기존 환경이 있으면 설치를 반복하지 않고 먼저 버전을 확인
.\.venv\Scripts\python.exe --version

# 새 환경인 경우에만
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt

# 임시 DB 자동 테스트
.\.venv\Scripts\python.exe -X utf8 -m pytest -q

# 서비스 시작. 같은 포트의 기존 프로세스를 무조건 종료하지 말 것
.\.venv\Scripts\python.exe -X utf8 start.py
```

## 10. 알려진 환경 주의점

Windows sandbox에서 TestClient socketpair/프로세스실행이완료출력없이멈춘전력이있다. 시간제한·프로세스상태·실행권한을점검하고코드테스트실패와구별한다. 이전실행세션ID/PID는재사용하지않는다. 정책에따라필요할때만실행권한을요청한다.
Microsoft Edge headless를사용하는Playwright테스트다. 새PC에Edge가없으면브라우저설치를별도확인한다.
공개운영준비가안된검수API가있다. 로컬서버를그대로인터넷에노출하는것을배포완료로취급하지않는다. 인증·공개범위·AI호스트접근·운영비를구체화한후진행한다.
