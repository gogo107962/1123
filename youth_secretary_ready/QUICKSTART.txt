청년비서 v0.8 — 무료 로컬 서비스

1. Windows: run_windows.bat 실행 (프로젝트 .venv 사용)
2. 브라우저 http://127.0.0.1:8000 열기 → 정책 검색 → 관심 저장 → 준비할 일 확인·승인 → 나의 준비판
3. AI 사용: PowerShell에서 .\run_ollama.ps1 실행 후 화면에서 로컬 AI 연결 다시 확인
4. 기존 가상 시연은 http://127.0.0.1:8000/lab → 서울 취업준비생 선택 → 조건/서류 확인 → 미리보기 승인 → 완료 상태 저장
5. AI가 제안한 정보는 확인 버튼으로 적용한 뒤 준비판을 별도 승인

판별용 3개는 가상 정책, 공식 정책 3개는 검수 대기 초안입니다. 실제 신청 대행은 없습니다.
자세한 검증과 남는 한계는 README.md / VALIDATION.md 참고.

추가 기능: 사용자 상황에서 가상 수급 이력을 저장한 뒤, 정책 선택 아래 공식 정책 초안의 가상 조건 검토 화면을 사용할 수 있습니다. 검수 시뮬레이션 결과는 실제 신청이나 준비판 저장이 아닙니다.

온통청년 연결: .local/ontong_api_key.txt에 키 한 줄 저장 → 화면 02의 온통청년 API 펼치기 → 연결 설정 다시 확인 → 정책 10건 가져오기.
가져온 정책은 검수 대기 DB에 저장됩니다. 신청기간·조건·서류를 공식 공고와 대조해야 하며, 아직 일반 자격 판별에는 사용하지 않습니다.
키 파일은 공유·제출하지 마세요. Ollama는 기존대로 로컬에서 실행합니다.

전체 DB 활용: 서비스 첫 화면에서 검색. 상세 검수는 /lab 화면 02 → 온통청년 영역 → 저장된 전체 정책 검색.
예: 정책번호 20261021005400214208 검색 → API와 공식 접수기간 차이 확인 → 연결된 규칙·서류 초안 검토.
성북구 응시료: 20240418005400200013 검색 → 조기 마감 근거 → 초안 검토 시각을 2026-11-16 12:00으로 설정해 접수 종료 확인.
검색·페이지 이동은 외부 API를 호출하지 않습니다. 원문 대조 기록이 있다고 전체 자격 검수가 끝난 것은 아닙니다.
